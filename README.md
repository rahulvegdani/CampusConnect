\# CampusConnect



CampusConnect is a student marketplace platform designed for college students to buy and sell products easily within their campus community.



\## Features



\- User Authentication

\- Product Listing

\- Wishlist

\- Real-time Chat

\- Notification System

\- User Profile Management

\- Seller Dashboard

\- Product Search \& Filter



\## Technologies Used



\- ASP.NET Core MVC

\- Entity Framework Core

\- SQL Server

\- Bootstrap

\- SignalR



\## Future Enhancements



\- AI-based recommendations

\- Mobile application

\- Online payment integration



\## Installation



1\. Clone repository

2\. Setup database

3\. Run migrations

4\. Start project
